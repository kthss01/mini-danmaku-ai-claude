Taisei Project 웹 버전

원본 C 게임을 Emscripten(WebAssembly)으로 빌드한 실험용 실행 페이지입니다.

브라우저 환경을 확인하는 중…

이 브라우저에서는 실행할 수 없습니다

    WebGL 2와 WebAssembly를 지원하는 최신 Chrome 또는 Edge에서 다시 열어주세요.

    시작 버튼을 누르면 게임 코드와 데이터를 내려받습니다. 첫 실행은 수백 MB를 받을 수 있고, 이후에는 브라우저 저장소에 캐시됩니다.

    소리는 브라우저 정책상 시작 버튼을 누른 뒤 키를 누르거나 화면을 클릭한 시점부터 재생됩니다.

    준비 중…

    게임을 실행하지 못했습니다

    
            
            
    페이지를 새로 고쳐 처음부터 다시 불러옵니다. 문제가 계속되면 아래 로그를 확인해주세요.

    키는 게임 내 설정 메뉴에서 바꿀 수 있습니다. 자동 발사는 설정 메뉴(Options)의 Shoot by default에서 끌 수 있고, 끄면 Z를 누르는 동안 발사합니다. 예전에 설정을 저장한 브라우저에서는 꺼진 상태가 남아 있을 수 있습니다. 브라우저 전체 화면은 F11 또는 화면 우측 상단 버튼을 사용합니다. 게임 패드 입력은 아직 웹에서 검증하지 않았습니다.
    
        
    

        
      
            
    • WebGL 2를 지원하는 최신 Chrome 또는 Edge를 권장합니다. 원본은 브라우저 실행을 전제로 설계되지 않았으므로 데스크톱판보다 느릴 수 있습니다.
      • 
            
    • 키 입력이 먹지 않으면 게임 화면을 한 번 클릭해 포커스를 맞춰주세요. 다른 창으로 전환하면 게임이 눌린 키를 해제하고 일시정지하도록 되어 있습니다(실제 브라우저에서의 확인은 진행 중).
      • 
            
    • 설정과 리플레이는 이 브라우저의 IndexedDB에 저장됩니다. 사이트 데이터를 지우면 함께 삭제됩니다.
