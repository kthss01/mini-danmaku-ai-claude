# Claude 주도 · Codex 보조 진행 가이드

## 현재 작업
[이슈 #2: 웹 전환](https://github.com/kthss01/mini-danmaku-ai-claude/issues/2)와 [상세 계획](WEB_PORT_PLAN.md)을 따른다. AI 구현은 웹 완료 이후다.

## 역할과 작업 단위
Claude: 조사·구현·실행 검증·문서·PR 생성·머지.
Codex: PR diff·재현 절차·실행 증거 검토 및 문제 정리.
사용자: 실제 화면 확인과 방향 결정.

모든 작업은 브랜치 → 커밋·push → PR → 검증·리뷰·수정 → 머지까지 진행한다. main 직접 push와 강제 push는 하지 않는다. 같은 파일을 동시에 수정하지 않는다.

## 브라우저를 통한 보고
Claude는 현재 브라우저 대화에 PR URL, head SHA, 검증 명령·결과, 실제 플레이 범위, 알려진 제약을 남긴다. Codex가 검토 결과를 이 대화로 전달하면 Claude가 수정한다. 이 대화를 도구 간 자동 통신 채널로 가정하지 말고 실제 보이는 보고를 기준으로 작업한다.

## 머지
보호 규칙과 필수 검사를 충족하고 리뷰에서 발견한 차단 문제가 해결되면 별도 재확인 없이 검증한 head를 머지한다. 필요한 외부 승인 등 차단이 있으면 우회하지 않고 보고한다. 자신의 PR에 허위 승인을 기록하지 않는다.
Taisei fork 수정은 fork PR을 먼저 머지한 후 메인 submodule 참조를 갱신한다.

## 검증
빌드 성공·초기 화면·실제 플레이를 구분한다. 실패·미검증을 성공으로 표시하지 않는다. 실시간 조작에 매 프레임 LLM 호출을 사용하지 않는다.
