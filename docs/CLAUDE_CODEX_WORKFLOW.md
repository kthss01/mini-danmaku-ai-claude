# Claude 주도 · Codex 보조 진행 가이드

## 목표
Taisei 원본을 로컬에서 실행한 뒤, AI 자동 플레이와 최고 난이도 공략, 탄막 시각 표현 개선으로 확장한다.

## 역할
- **Claude(주 담당)**: 소스 분석, 환경 구축, 기능 구현, 오류 수정, 실행 결과 및 문서 작성.
- **Codex(보조)**: Claude가 완료한 커밋의 코드 리뷰, 재현 절차·검증 결과 확인, 발견한 문제의 정리. 수정은 별도 요청한 범위에서 수행.
- **사용자**: 실제 PC에서 화면 실행 확인, 우선순위와 결과 판단.

## 작업 방식
1. Claude에 이 이슈의 현재 단계만 요청한다.
2. Claude는 작업 브랜치에서 구현하고 검증 결과를 남긴다.
3. Codex에 브랜치 또는 커밋과 검증 결과를 전달하여 검토를 요청한다.
4. 발견한 문제는 Claude가 수정하고 필요한 검증을 다시 수행한다.
5. 확인된 결과를 커밋·push하고 체크리스트를 갱신한다.

같은 작업 폴더에서 두 도구가 동시에 파일을 수정하지 않는다.
리뷰 시 Codex는 우선 읽기 전용으로 동작하고, 심각도·파일 위치·재현 조건을 기준으로 문제를 보고한다.
실시간 게임 조작은 로컬 알고리즘이 수행하며, 매 프레임 LLM API를 호출하지 않는다.

## 단계별 체크리스트
### 1. 초기 환경 구축 — 지금 진행할 범위
- [ ] 기존 지침·브랜치·미커밋 변경 확인
- [ ] 실제 fork 주소 확인 후 game/taisei에 submodule 연결
- [ ] origin은 fork, upstream은 공식 저장소로 설정
- [ ] 공식 빌드 안내·라이선스 확인 및 기준 커밋 기록
- [ ] Windows 빌드 도구·의존성 준비
- [ ] Taisei 원본 빌드 성공
- [ ] 사용자 PC에서 게임 화면 실행 확인
- [ ] docs/SETUP.md에 재현 절차와 실제 결과 기록
- [ ] Claude 주 담당·Codex 보조 운영 방침을 프로젝트 문서에 반영
- [ ] 변경 검토 후 커밋·push

### 2. 관측·입력 연동
- [ ] 플레이어·탄·레이저 상태와 게임 루프 구조 분석
- [ ] 상태 추출과 프레임 단위 자동 입력 구현
- [ ] 반복 실행·초기화·시드 제어 지원 여부 확인
- [ ] 한 패턴에서 관측에 따른 이동 확인

### 3. 자동 회피 및 난이도 확장
- [ ] 규칙 기반 충돌 예측·이동 후보 평가 구현
- [ ] 저속 이동·공격·봄 사용 정책 추가
- [ ] 생존 시간·피격·봄·클리어·판단 시간 기록
- [ ] 한 패턴 → 한 스테이지 → 최고 난이도 전체 순서로 검증
- [ ] 원래 게임 규칙에서의 리플레이와 재현 정보 확보

### 4. 시각 표현 및 시연
- [ ] 색상·잔상·밝기 등 표현 프리셋 구현
- [ ] 동일 리플레이로 원본과 비교
- [ ] 원래 규칙의 클리어와 패턴 변경 실험 구분
- [ ] FPS·프레임 지연 및 공개 자료의 라이선스 확인
- [ ] 시연 영상·실행 안내 정리

## 일정과 완료 기준
- 1~2주 집중 목표: 원본 실행 → 상태·입력 연동 → 한 패턴 또는 한 스테이지 자동 플레이 시연.
- 최고 난이도 전체 클리어는 별도 검증 목표이며 1~2주 내 달성을 보장하지 않는다.
- 빌드 성공과 실제 화면 실행 확인을 구분한다.
- 특정 시드 1회 성공과 여러 시드 반복 성공을 구분한다.
- 현재 로컬 구축 진행 상황은 아직 확인되지 않았으므로 체크리스트는 완료 증거에 따라 갱신한다.

## Claude 첫 요청
> 이 이슈의 1단계 초기 환경 구축을 진행해줘. 기존 지침과 변경을 보존하고 실제 fork 주소와 현재 연결 상태부터 확인해줘. Taisei 공식 빌드 안내에 따라 원본을 빌드하고 가능한 범위에서 실행해줘. docs/SETUP.md에 환경·게임 커밋·명령·실제 결과를 기록해줘. AI 기능은 다음 단계로 남겨줘. 변경을 검토한 뒤 이번 작업만 커밋·push하고, 결과 커밋과 남은 문제를 알려줘. 강제 push는 하지 마.

## Codex 리뷰 요청
> Claude가 완료한 이 이슈의 변경을 검토해줘. 대상 브랜치/커밋: [입력]. 우선 파일 수정 없이 정확성, 빌드 재현성, submodule 및 원격 설정, 문서와 실행 결과의 일치 여부를 확인해줘. 문제는 심각도·파일 위치·근거·재현 조건과 함께 알려줘. 검증하지 못한 내용과 남은 위험도 구분해줘.
