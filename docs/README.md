# 문서 안내

프로젝트에서 검증된 사실과 실행 절차를 관리합니다.

- `PROJECT_PLAN.md`: 목표, 단계별 일정 및 검증 기준
- `SETUP.md`: Taisei 기준 버전과 설치·빌드·실행 절차(환경 검증 후 추가)
- `ARCHITECTURE.md`: 게임 상태, 입력 지점 및 프로세스 간 연동 설계(소스 분석 후 추가)
- `EXPERIMENTS.md`: 실행 조건, 지표, 결과 및 실패 원인(첫 실험부터 추가)
- `VISUALS.md`: 시각 표현 프리셋과 성능 비교(자동 플레이 기준선 이후 추가)

검증하지 않은 명령이나 결과는 성공한 절차로 기록하지 않습니다.
