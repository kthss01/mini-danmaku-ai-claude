# 한국어 번역 (게임 언어 `ko`)

추적 이슈: [#28](https://github.com/kthss01/mini-danmaku-ai-claude/issues/28)의 하위 이슈 "[웹/후속] 게임 한국어 지원"

Taisei의 gettext 다국어 기능에 한국어(`ko`)를 추가한 기록이다. 번역 원본은 fork `kthss01/taisei`의 `po/ko.po`이고, 이 문서는 번역 규칙·용어표·동작 방식을 적는다.

## 1. 동작 방식

- 게임 옵션의 **Language** 항목에서 `System` / `English` / `한국어` / `Deutsch` / `Français` / `简体中文` 중 고른다.
- 기본값은 `System`이다. 브라우저 언어(`SDL_GetPreferredLocales`)가 한국어(`ko`, `ko-KR`)이면 **처음부터 한국어로 시작**한다. 한국어가 아닌 브라우저는 지금까지처럼 영어(또는 해당 언어)로 시작한다.
- 선택은 다른 설정과 같이 브라우저 IndexedDB에 저장된다.
- 한글 글꼴은 새로 추가하지 않았다. 기존 CJK 글꼴 `SourceHanSans-Regular-0.ttf`(본문·작은 글씨)와 `SourceHanSerifSC-Heavy.ttf`(큰 제목)가 한글 음절 11,172자를 모두 갖고 있고, 라틴 글꼴(`standard.font` 등)의 `fallbacks = *_cjk` 설정으로 글자 단위 대체가 일어난다. 그래서 로캘별 글꼴 전환 코드는 필요 없다.
- 번역하지 않은 문자열은 영어로 나온다(gettext 기본 동작).

## 2. 번역 규칙

- 형식 지정자(`%s`, `%d`, `%i`, `%g`, `%X`)는 개수·순서를 원문과 같게 둔다. 개수가 다르면 게임이 번역을 버린다.
- `\n`(줄바꿈)은 원문 위치와 개수를 유지한다. 문자열이 `\n`으로 시작하거나 끝나면 번역도 똑같이 한다.
- `*강조*`, `“ ”`, `‘ ’`, `…`, `—`, `№`, `[Fire]` 같은 기호와 자리 표시자는 그대로 둔다.
- 말투는 화자별로 구분한다(3장). 화자는 msgid에 없고 소스(`src/cutscenes/*.inc.h`, `src/dialog/*.c`)의 `T_<이름>(...)` 매크로로 알 수 있다.
- 노래 제목과 작곡가 이름은 번역하지 않는다. 곡 설명만 번역한다.
- 게임 이름 `Taisei Project`와 `ZUN`, `Team Shanghai Alice`는 그대로 둔다.

## 3. 화자별 말투

| 화자 | 말투 |
| --- | --- |
| 나레이션 | 서술체(`~했다`, `~였다`) |

| 마리사 | 호쾌한 반말(`~다구`, `~인걸`, `~란 말이야`) |
